# Pokémon League

## Autor/a
Adan López Gil

## Descripció
Aplicació per gestionar equips, lligues i un mercat de fitxatges de Pokémon.

## Versions utilitzades
Node.js: 24.21.0 
npm: 11.19.0
Angular CLI: 22.2.1
Git: 2.56.0.windows.1

## Com crear i executar el projecte
Comanda de creació: `ng new ioc-angular-pokemon-league-adan-lopez --routing --style=scss --ssr=false --standalone --file-name-style-guide=2016 --skip-git --package-manager=npm`
Per executar el projecte: `ng serve`
